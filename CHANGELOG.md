## 1.0.0

- Initial release.
- Per-flavor dependency overrides from one `flavor_overrides.yaml`, written to
  `pubspec_overrides.yaml` of every package in the project that uses an overridden package.
- Works with a single package, a pub workspace, `path:` modules and melos.
- `--flavor`, `--clean`, `--dry-run`, `--list-dependents`, `-C`.
